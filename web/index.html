Macros

Sleep after

Idle time before the keyboard sleeps in 2.4G or Bluetooth mode. 30 minutes is the longest the firmware offers.

Key response

1 is fastest, 5 filters the most switch bounce. Raise it if keys double-type. The factory default is 2.

Block keys

Stops these keys from closing or leaving a game by accident.

Fn switch

When on, the top row sends media keys without holding Fn. When off, it sends F1–F12.

The keyboard can't report these settings, so this page shows the last values applied from here, or the factory defaults. Apply writes all of them at once.
